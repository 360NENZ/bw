# BW 历年纪念页面

以 Bilibili World 官网历年主视觉为背景的非官方静态页面，提供开场倒计时、活动期间正计时和落幕正计时，无构建依赖。默认展示 BW 2026。

## 预览与链接参数

在项目目录运行 `python -m http.server 8080`，访问 <http://localhost:8080/>。也可以直接打开 `index.html`，年份配置和素材均保存在本地。

| 参数 | 示例 | 效果 |
| --- | --- | --- |
| `year` | <http://localhost:8080/?year=2025> | 按年份切换主视觉、站点图标、活动日期、场地、标题和计时基准 |
| `station` | <http://localhost:8080/?year=2019&station=chengdu> | 选择同年站点：`guangzhou`（广州）、`shanghai`（上海）、`chengdu`（成都），仅接受当年存在的站点 |
| `showHours=1` | <http://localhost:8080/?year=2025&showHours=1> | 展示「每日 08:00–18:00」及夜间开放时间提示 |

时间提示默认隐藏。参数应放在 `#` 之前；已有参数时使用 `&` 连接。右上角「历年」菜单也可以切换年份，并保留 `showHours` 等已有查询参数；切换年份时清除旧站点参数，避免带入不存在的城市。2019、2020 的信息卡内可直接切换站点，地址可收藏或分享。

`year` 接受四位数字。[`?year=2022`](http://localhost:8080/?year=2022) 展示因疫情影响未举办的年度记录、原定日期和延期公告；不运行计时，也不展示寄语或每日开放时间，即使带有 `showHours=1`。未收录年份（例如 `?year=2017`、`?year=2030`）会显示缺少可验证资料的提示，隐藏计时与背景；不会借用 2026 的日期或视觉。格式错误（例如 `?year=abc`）会提示正确用法。

## 素材与归档来源

页头使用官网应用内的 Bilibili World 白色 SVG 标识，下面保留当前年份；浏览器图标和手机主屏幕图标随所选年份切换，逐年采用仍在线官网 HTML 引用的原始图标：2018–2019 为小电视星星，2020–2021 为闪电，2023 为当年 BW 标识，2024–2026 为粉色小电视星球。2023 原 favicon 目前返回纯蓝方块，改用当年导航栏完整 BW 标识。部分年份官方本身复用图标，因此保留真实映射；2022、未收录或错误年份使用默认星球图标。素材均本地保存，提取方式及来源记录在 `assets/sources.json` 的 `identity` 中。页面省去素材形式与身份说明，资料详情集中在页脚「资料来源」入口，寄语保留原文和署名。

2026-11-23 至 24 日通过 [Wayback Machine](https://web.archive.org/) 的 CDX 与历史页面定位历年资源，再核对归档应用、页面和海报中的活动日期。逐年归档地址、原始素材 URL、获取方式、画面覆盖范围及日期证据见 [assets/sources.json](assets/sources.json)。素材版权归原权利方所有。

归档候选按活动前后跨年度检索：多数年份的官网从当年活动开始前约一个月至下一届开始前约一个月保留当届页面，因此下一年抓取的快照也可能属于上一届。这个区间只用于扩大搜索范围；最终以页面标题、海报年份、日期和应用内容确定届数，不能将抓取年份直接当作活动年份。

历史 HTML 有些动态依赖未被归档。对这些资源，沿归档页面所引用的原始 CDN 补取，并在来源记录中标明；并非所有素材文件都由 Wayback 返回。2020 视频直接取自 Wayback。2018 用归档 HTML、JS、CSS 及原 CDN 模型、纹理恢复首页，保存整幅静帧，包含原页面标志、日期与 START 字样。

优先从仍在线的 `https://bw.bilibili.com/<年份>/` 及其原始 CDN 获取资源，Wayback 用于补充历史证据。大文件下载允许每次最长 600 秒并重试三次；网络超时不代表没有动态 KV。2024、2025 的完整动态 KV 已成功取回，继续保留对应官网原始海报，不从视频重截图片。

2021 使用仍在线的[官方页面](https://bw.bilibili.com/2021/index.html#/Home)加载背景动画，原视频为 1920×1080、4 秒。保留前 2 秒，去除进度层和模糊变暗退场，播放一次后停留在清晰的实际末帧。未取得同构图完整原图的年份保留已明确标注来源的视频静帧；有完整原图的年份直接使用原图。

2022 的[延期公告转载](https://www.onsiteclub.com/case/BW2022-Announced-Delay-Or-That-2022-5-24)包含 BilibiliWorld 园长微博截图和完整官方公告，明确说明疫情防控、疫情反弹风险及观众健康安全是延期原因，原定日期为 7 月 15–17 日。公告落款为 **2022 年 5 月 23 日**，转载发布于 5 月 24 日。官方当时的措辞是「延期举办」；[百度百科的 BW 历史记录](https://baike.baidu.com/en/item/BiliBili%20World/1469626)另记载当年因 COVID-19 取消，下一届于 2023 年举办。页面以「当年未举办」说明结果，并区分延期公告和后续记录，不声称取得了官方取消公告。

尚未找到可验证的 2022 独立主 banner，因此该年份使用 CSS 绘制参考公告配色的蓝色条纹背景，并明确标注。完整 1080×3399 公告原图保存在本地，可从「查看延期公告全文」打开；它是历史资料，不作为背景主图，也不替用其他年份素材。「回望 BW 2023」链接保留已有查询参数。

2023 使用[仍在线的官网页面](https://www.bilibili.com/blackboard/bw/2023/index.html)配置的 `loadingKv` 完整原图：3000×1688 JPEG，不含招商信息，替换原先的「恋恋心声」PAG 静帧。原图直接从官方 CDN 获取，未裁剪或重新拼接，与[宣传 PV](https://www.bilibili.com/video/BV1i14y1m7DA)封面及[4 月招商页存档](https://web.archive.org/web/20230401181517/https://bw.bilibili.com/)使用同一套人物主视觉。活动日期继续使用 7 月官网资料核对的 7 月 21–23 日。

页面读取图片的原始宽高自动判断横竖版，不依赖年份或文件名。横图居中铺满屏幕；竖图按比例完整展示，用同图的模糊背景填充剩余空间。窗口变化时由 CSS 自动重新适配，素材文件保持原样。另按视口横竖屏选择素材：已有对应竖版原图的 2019 三站，在竖屏优先显示完整海报，不加载横版视频；旋转为横屏后恢复动态 KV，转回竖屏即暂停并隐藏视频。保留用户手动暂停与系统减少动态效果的选择。其他年份没有匹配竖版素材时继续原有展示，不裁出伪竖版图片。

页面字体随项目本地提供：中文与界面使用 Noto Sans SC 可变字体子集，计时数字使用 Barlow Semi Condensed 600，两份 WOFF2 合计约 161KB，采用预加载及 `font-display: swap`。字体加载时先显示系统回退字体；运行时不连接外部字体服务，来源、哈希与 SIL OFL 授权保存在 `assets/fonts/`。Noto 子集覆盖当前 HTML、年份配置及脚本文字；增加新文案后可用 `scripts/subset-fonts.py` 重新生成，需要 Python 的 `fonttools[woff]` 和来源记录中的原始 TTF。

计时格子按天数位数分配宽度，数字按实际字体字宽与格子可用宽度缩放，保留完整数值。数值更新、窗口变化和字体加载完成都会重新测量，字体加载失败时同样适配回退字体。页面使用 `text-size-adjust: 100%` 避免手机浏览器自动放大文字改变布局，保留用户手动缩放能力。

所有展示素材均本地加载，页面运行时不请求 Wayback 或外部 CDN。2019 三站、2020 两站、2024、2025、2026 的动态 KV 默认持续循环；2021 的加载动画播放一次后停留在清晰末帧，按钮变为「重播背景」。2020 上海去掉白色淡出，将原片 0.6–10.4 秒的尾部 0.6 秒与原片开头 0–0.6 秒叠化，生成 9.8 秒循环，跨边界继续原动画运动，减轻白屏和硬切。

播放中可以暂停或继续；切到后台暂停，返回时继续未被手动暂停的动画。2021 已结束的动画不会因切回页面、旋转屏幕或更改动态设置而自动重播。视频失败时显示本地海报；系统启用「减少动态效果」时默认不加载视频，可手动播放。2018 保留官网 3D 首页静帧；2023 按已选主视觉保留 `loadingKv` JPEG 原图，官网其他主题的 PAG 动画并非同一人物主图，不作替换。

## 计时与寄语

各届统一使用用户指定的北京时间每日 **08:00–18:00**。这是一致的计时约定，不声明为历年官方开放时间；`showHours` 只控制文字提示。

| 时间阶段 | 展示内容 | 基准 |
| --- | --- | --- |
| 首日 08:00 前 | 距 BW 年份 开场还有 | 倒计时至首日开馆 |
| 首日 08:00 至末日 18:00 前 | BW 年份 已开场 | 从首日开馆起连续正计时，包含夜间 |
| 末日 18:00 起 | 距 BW 年份 落幕已经 | 从整届落幕起正计时 |

状态标签按北京时间区分「今日尚未开馆」「现场开放中」「今日已闭馆」。日期明确指定 `+08:00`，不随访问者时区改变；每秒更新，并在边界自动切换。

打开或刷新页面时，仅在活动期间每日 18:00 闭馆后至次日 08:00 前，或整届落幕后展示寄语弹窗。活动前及每日开放期间不展示；没有「不再显示」或持久化跳过标记。点击「好的，收到」或按 Esc 关闭后，焦点回到计时区；小屏弹窗可以滚动。

各年份使用同一段小园长寄语和署名，只替换「哔哩哔哩 · BilibiliWorld 年份」中的年份。其余寄语和说明文字保持一致，不增加寄语年份来源提示；弹窗展示时机仍按当前选择的活动年份判断。

2022 因当年未举办，没有实际开场或落幕时间，任何访问日期都不运行倒计时或正计时、不弹出闭馆寄语。原计划日期仅供回顾，不代表活动实际举办。

## 扩展与验证

新增举办年份时，在 `events.js` 中加入真实日期、场地、本地海报和可选视频，同时更新 `assets/sources.json` 的归档来源与覆盖范围。年份菜单由配置自动生成。未举办年份用 `status: 'not-held'` 表示，实际日期和计时边界为 `null`，原定日期另存；`getClock` 返回 `null`，不触发寄语。

运行 `node --test tests/countdown.test.cjs`，验证年份解析、真实日期、各届开闭馆与落幕边界、长期正计时及本地素材。已使用 Edge / Playwright 检查所有收录年份、缺失与错误参数、时间提示组合、各年份寄语一致性、菜单切换、320px 与 360px 布局、视频开关、失败回退和直接打开本地 HTML。2021 加载动画的播放结束停留、手动重播、后台返回与减少动态效果切换不重播、完整海报和官方页面链接也已验证。

2022 新增验证覆盖公告前后、原定开闭馆时刻及多年以后均无计时和寄语；20 项逻辑测试通过（包含新增站点）。Edge 检查 1440、1024、768、700、360、320px 六种宽度无横向溢出，确认 `showHours=1` 仍隐藏开放时间、不加载其他年份主图或视频、公告图片可本地访问、切换 2023 保留参数；其他八个举办年份、缺失参数和本地 HTML 加载均通过。

手机字体及计时布局回归检查为 `node tests/mobile-layout.check.cjs`，需要 Node 可找到 Playwright、已安装 Edge，且本地 HTTP 服务在 8080 端口运行（可用 `BW_TEST_URL` 指定其他地址）。检查移动端触控与三倍像素密度、320–1440px 八种宽度、字体正常/延迟/失败回退及四至七位天数，用文字实际宽度确认数字未超出格子，而非只检查页面是否横向滚动。该检查使用 Edge 的手机模拟，未代替真机浏览器验证。

制作鸣谢：lrastar / Gemini3 Pro / 360NENZ / Codex（gpt-6.1-sol） / Antigravity（Gemini 3.8 Flash）。

站点回归检查为 `node tests/stations.check.cjs`：核对五个站点的日期、场地、主图、链接参数、站点/年份切换及 320–1440px 布局。视频回归检查为 `node tests/background-video.check.cjs`：核对各站持续循环、2020 上海叠化接缝、2021 播放结束停留与海报一致性、手动重播、暂停继续、后台返回及减少动态效果设置。逐年图标和横竖屏检查为 `node tests/year-assets.check.cjs`，覆盖图标文件访问、年份回退、竖屏不下载横版视频和旋转时播放状态。
