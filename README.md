# BW 历年纪念页面

以 Bilibili World 官网历年主视觉为背景的非官方静态页面，提供开场倒计时、活动期间正计时和落幕正计时，无构建依赖。默认展示 BW 2026。

## 预览与链接参数

在项目目录运行 `python -m http.server 8080`，访问 <http://localhost:8080/>。也可以直接打开 `index.html`，年份配置和素材均保存在本地。

| 参数 | 示例 | 效果 |
| --- | --- | --- |
| `year` | <http://localhost:8080/?year=2025> | 按年份切换主视觉、活动日期、场地、标题和计时基准 |
| `showHours=1` | <http://localhost:8080/?year=2025&showHours=1> | 展示「每日 08:00–18:00」及夜间开放时间提示 |

时间提示默认隐藏。参数应放在 `#` 之前；已有参数时使用 `&` 连接。右上角「历年」菜单也可以切换年份，并保留 `showHours` 等已有查询参数。

`year` 接受四位数字。未收录年份（例如 `?year=2022`、`?year=2030`）会显示缺少可验证资料的提示，隐藏计时与背景；不会借用 2026 的日期或视觉。格式错误（例如 `?year=abc`）会提示正确用法。

## 素材与归档来源

2026-11-23 至 24 日通过 [Wayback Machine](https://web.archive.org/) 的 CDX 与历史页面定位历年资源，再核对归档应用、页面和海报中的活动日期。逐年归档地址、原始素材 URL、获取方式、画面覆盖范围及日期证据见 [assets/sources.json](assets/sources.json)。素材版权归原权利方所有。

历史 HTML 有些动态依赖未被归档。对这些资源，沿归档页面所引用的原始 CDN 补取，并在来源记录中标明；并非所有素材文件都由 Wayback 返回。2020 视频直接取自 Wayback；2023 海报由取自 Wayback 的 PAG 渲染。2018 用归档 HTML、JS、CSS 及原 CDN 模型、纹理恢复首页，保存整幅静帧，包含原页面标志、日期与 START 字样。

2021 只复原已提取的官网首页角色层，铺设粉色底，未将模糊占位图或带加载进度的开场动画用作完整 banner。2023 使用默认「恋恋心声」场景，而非拼接全部主题。2024、2025 的主 KV 视频取回超时，保留已核对的完整海报。

所有展示素材均本地加载，页面运行时不请求 Wayback 或外部 CDN。2019、2020、2026 可以播放背景视频；其他年份隐藏视频按钮。视频失败时显示本地海报；系统启用「减少动态效果」时默认不加载视频，可手动播放。页面切到后台会暂停背景。

## 计时与寄语

各届统一使用用户指定的北京时间每日 **08:00–18:00**。这是一致的计时约定，不声明为历年官方开放时间；`showHours` 只控制文字提示。

| 时间阶段 | 展示内容 | 基准 |
| --- | --- | --- |
| 首日 08:00 前 | 距 BW 年份 开场还有 | 倒计时至首日开馆 |
| 首日 08:00 至末日 18:00 前 | BW 年份 已开场 | 从首日开馆起连续正计时，包含夜间 |
| 末日 18:00 起 | 距 BW 年份 落幕已经 | 从整届落幕起正计时 |

状态标签按北京时间区分「今日尚未开馆」「现场开放中」「今日已闭馆」。日期明确指定 `+08:00`，不随访问者时区改变；每秒更新，并在边界自动切换。

打开或刷新页面时，仅在活动期间每日 18:00 闭馆后至次日 08:00 前，或整届落幕后展示寄语弹窗。活动前及每日开放期间不展示；没有「不再显示」或持久化跳过标记。点击「好的，收到」或按 Esc 关闭后，焦点回到计时区；小屏弹窗可以滚动。

保留用户提供的 BW 2026 小园长寄语原文及署名。回望历史年份时，弹窗说明当前年份并注明「以上小园长寄语来自 BW 2026」，不将其改写成往届官方寄语。

## 扩展与验证

新增年份时，在 `events.js` 中加入真实日期、场地、本地海报和可选视频，同时更新 `assets/sources.json` 的归档来源与覆盖范围。年份菜单由配置自动生成，不需要修改 HTML 或计时逻辑。

运行 `node --test tests/countdown.test.cjs`，验证年份解析、真实日期、各届开闭馆与落幕边界、长期正计时及本地素材。已使用 Edge / Playwright 检查所有收录年份、缺失与错误参数、时间提示组合、历史寄语来源、菜单切换、320px 与 360px 布局、视频开关、失败回退和直接打开本地 HTML。
